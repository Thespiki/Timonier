# Translation glossary

Terms that must be translated consistently everywhere. The reference language is English (US); the French column is
the original wording. When a term is a Windows feature or a Windows UI label, use **the name Windows itself displays
in the target language** (Settings app, File Explorer, Task Manager…), not a literal translation.

## Style

- Short, friendly, plain language; address the user as "you".
- Keep every placeholder (`{0}`, `{1:N0}`…) exactly; you may move it within the sentence.
- Units: o/Ko/Mo/Go/To → B/KB/MB/GB/TB (or the target language's usual abbreviations).
- Quotes: use the typographic quotes of the target language (English: “…”).
- Menu paths use "›" as in the original: Settings › System › Storage.
- Search keyword lists (comma-separated) are translated as keyword lists: keep product names and English technical
  terms, add the words people in that language would type.
